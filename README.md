# Combo Arena

Экшн-рогалик на C# (MonoGame) про битву с волнами врагов на арене.

## Описание игры

**Combo Arena** - это 2D пиксель-арт игра, где вы управляете героем, сражающимся с бесконечными волнами врагов. Убивайте врагов, накапливайте комбо, повышайте уровень, выбирайте перки и выживайте как можно дольше.

## Особенности

- **3 типа врагов**: Красный (быстрый, ярость), Синий (средний, рывок), Жёлтый (тяжёлый, лазер)
- **4 ранга врагов**: Normal → Elite → Champion → Boss (с повышением сложности)
- **Система комбо**: цепочка атак в течение 3 секунд - +5% урона и +3% опыта за каждое комбо
- **Активные способности**: FireBurst (огненный взрыв) и Barrier (щит неуязвимости)
- **14 перков**: улучшение урона, скорости, здоровья, дальности, вампиризм, усиление опыта и способностей
- **Система уровней**: получайте опыт за убийства, повышайте уровень, выбирайте перк каждые 3 уровня
- **Динамическая сложность**: враги становятся сильнее вместе с вами
- **Дроп**: враги оставляют сферы опыта и сердечки здоровья

## Как играть

Запустите игру через IDE или собранный исполняемый файл.

**Управление:**

W / Стрелка вверх - движение вверх
A / Стрелка влево - движение влево
S / Стрелка вниз - движение вниз
D / Стрелка вправо - движение вправо
Space - атака
E - активная способность
Escape - пауза
1 / 2 / 3 - выбор перка

**Цель игры:**

- Уничтожать врагов, избегая получения урона
- Строить комбо для максимального урона и опыта
- Выбирать перки, которые подходят вашему стилю игры
- Выживать как можно дольше

## Установка и запуск

### Запуск из исходного кода

```
dotnet build ComboArena/ComboArena.csproj -c Release
dotnet run --project ComboArena/ComboArena.csproj -c Release
```

### Запуск готовой сборки

```
dotnet publish ComboArena/ComboArena.csproj -c Release -r win-x64 --self-contained true -o publish_final
publish_final\ComboArena.exe
```

## Структура проекта

Проект использует архитектуру MVC (Model-View-Controller):

Controller/ - игровая логика (спавн, коллизии, перки, дроп)
Model/ - сущности (игрок, враги, способности, перки, дроп)
View/ - рендеринг, HUD, экраны меню
Core/ - система событий (EventBus)
Content/ - графические ресурсы (текстуры, шрифты)

## Тестирование

```
dotnet test tests/ComboArena.Tests.csproj
```

17 xUnit-тестов покрывают основную логику: движение, коллизии, урон, комбо, уровни, перки, масштабирование сложности.
